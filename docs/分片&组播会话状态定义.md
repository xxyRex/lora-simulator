## **分片会话状态（FSS）定义**

```Plain
FS_STATUS_PENDING                          = 0  // 分片会话待处理 - 尚未开始分片会话
FS_STATUS_SESSION_ATTEMPTING               = 1  // 正在尝试建立分片会话 - 已发送分片会话设置命令
FS_STATUS_SESSION_READY                    = 2  // 分片会话已就绪 - 设备已确认分片会话设置
FS_STATUS_IN_SESSION                       = 3  // 分片会话进行中 - 正在接收固件片段
FS_STATUS_FRAG_SESSION_SETUP_TIMEOUT       = 4  // 分片会话设置超时 - 设备未响应分片会话设置命令
FS_STATUS_WRONG_DESCRIPTOR                 = 5  // 描述符错误 - 设备报告分片描述符不匹配
FS_STATUS_FRAG_SESSION_INDEX_NOT_SUPPORTED = 6  // 不支持分片会话索引 - 设备不支持指定的分片会话索引
FS_STATUS_NOT_ENOUGH_MEMORY                = 7  // 内存不足 - 设备没有足够的内存处理分片
FS_STATUS_ENCODING_UNSUPPORTED             = 8  // 不支持的编码 - 设备不支持指定的分片编码方式
FS_STATUS_MISSING_FRAG                     = 9  // 缺少分片 - 设备未接收到完整的分片集
FS_STATUS_UPGRADE_FAILED                   = 10 // 升级失败 - 固件升级过程未成功完成
FS_STATUS_SESSION_FAILED                   = 11 // 会话失败 - 分片会话过程中发生错误
FS_STATUS_SESSION_DONE                     = 12 // 会话完成 - 分片传输已完成
FS_STATUS_UPGRADE_DONE                     = 13 // 升级完成 - 设备已成功应用固件更新
FS_STATUS_UPGRADE_TIMEOUT                  = 14 // 升级超时 - 固件升级过程超时
FS_STATUS_STATUS_TIMEOUT                   = 15 // 状态报告超时 - 设备未能在规定时间内报告状态
FS_STATUS_OTHER_ERROR                      = 16 // 其他错误 - 分片会话过程中发生未定义的错误
FS_STATUS_FIRMWARE_VERIFIED                = 17 // 固件已验证 - 设备校验固件CRC成功
FS_STATUS_PACKAGE_VERSION_ATTEMPTING       = 18 // 正在确认FBDT软件包版本 - 已发送PackageVersionReq等待响应
FS_STATUS_PACKAGE_VERSION_CONFIRMED        = 19 // FBDT软件包版本已确认 - 设备已确认支持分片功能
FS_STATUS_PACKAGE_VERSION_NOT_SUPPORTED    = 20 // FBDT软件包版本不支持 - 设备不支持分片功能或版本不匹配
FS_STATUS_PACKAGE_VERSION_TIMEOUT          = 21 // FBDT软件包版本确认超时 - 设备未响应PackageVersionReq

```

## **多播会话状态（MS）定义**

```Plain

MS_STATUS_PENDING                          = 0  // 组播会话待处理 - 尚未开始组播会话
MS_STATUS_SESSION_ATTEMPTING               = 1  // 正在尝试建立组播会话 - 已发送组播设置命令
MS_STATUS_SESSION_GROUP_SETUP_DONE         = 2  // 组播组设置完成 - 设备已确认组播组设置
MS_STATUS_SESSION_READY                    = 3  // 组播会话已就绪 - 设备准备好接收组播数据
MS_STATUS_IN_SESSION                       = 4  // 组播会话进行中 - 正在接收组播数据
MS_STATUS_SESSION_DONE                     = 5  // 组播会话完成 - 所有数据已成功传输
MS_STATUS_MC_GROUP_SETUP_TIMEOUT           = 6  // 组播组设置超时 - 设备未响应组播组设置命令
MS_STATUS_MC_GROUP_SETUP_ID_ERROR          = 7  // 组播组ID错误 - 设备报告组播组ID不匹配
MS_STATUS_MC_CLASS_SESSION_REQ_TIMEOUT     = 8  // 组播会话请求超时 - 设备未响应组播会话请求
MS_STATUS_MC_GROUP_ID_UNDEFINED            = 9  // 组播组ID未定义 - 设备报告指定的组播组ID不存在
MS_STATUS_MC_FREQ_ERROR                    = 10 // 频率错误 - 设备不支持指定的组播频率
MS_STATUS_MC_DR_ERROR                      = 11 // 数据速率错误 - 设备不支持指定的组播数据速率
MS_STATUS_MC_GROUP_ID_NOT_MATCH            = 12 // 组播组ID不匹配 - 设备报告组播组ID与预期不符
MS_STATUS_OTHER_ERROR                      = 13 // 其他错误 - 组播会话过程中发生未定义的错误
MS_STATUS_PACKAGE_VERSION_CONFIRMED        = 14 // 组播软件包版本已确认 - 设备已确认支持组播功能
MS_STATUS_PACKAGE_VERSION_NOT_SUPPORTED    = 15 // 组播软件包版本不支持 - 设备不支持组播功能或版本不匹配
MS_STATUS_PACKAGE_VERSION_TIMEOUT          = 16 // 组播软件包版本确认超时 - 设备未响应PackageVersionReq
MS_STATUS_PACKAGE_VERSION_ATTEMPTING       = 17 // 正在确认组播软件包版本 - 已发送PackageVersionReq等待响应
MS_STATUS_MC_GROUP_SETUP_PAYLOAD_TOO_LARGE = 18	//负载超过最大负载限制 - McGroupSetupReq负载超过设备RX窗口最大负载限制
```
