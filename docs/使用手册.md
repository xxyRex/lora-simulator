## 快速开始

### 5 分钟快速体验

```bash
# 1. 编译程序
make build

# 2. 进入运行目录
cd cmd/lora-simulator

# 3. 编辑配置文件（修改服务器地址和认证信息）
vi config/lora-simulator.toml

# 4. 运行模拟器
./lora-simulator -c config/lora-simulator.toml

# 5. 查看日志
tail -f simulator.log

# 6. 查看 Prometheus 指标（另开终端）
curl http://localhost:9000/metrics
```

## 安装部署

### 系统要求

**硬件要求**：
- CPU：2 核心或以上
- 内存：2 GB 或以上（大规模模拟建议 4 GB+）
- 磁盘：100 MB 空闲空间

**软件要求**：
- 操作系统：Linux / macOS / Windows
- Go 版本：1.23.0 或更高
- Git（用于克隆代码）

**网络要求**：
- 能访问 ChirpStack Application Server
- 能访问 MQTT Broker
- 能访问 ChirpStack Network Server（通过 MQTT）

### 下载源码

```bash
# 使用 Git 克隆代码仓库
git clone https://github.com/brocaar/lora-simulator.git
cd lora-simulator
```

### 编译安装

#### 方法 1：使用 Makefile（推荐）

```bash
# 编译（生成二进制文件到 cmd/lora-simulator/lora-simulator）
make build

# 清理构建文件
make clean

# 使用自定义构建参数
GO_EXTRA_BUILD_ARGS="-v" make build
```

#### 方法 2：手动编译

```bash
# 获取依赖
go mod download

# 编译
go build -ldflags "-s -w -X main.version=$(git describe --always)" \
    -o cmd/lora-simulator/lora-simulator \
    cmd/lora-simulator/main.go
```

### 验证安装

```bash
cd cmd/lora-simulator
./lora-simulator --version
```

**预期输出**：
```
lora-simulator version x.x.x
```

## 配置说明

### 配置文件层次结构

```
cmd/lora-simulator/
├── config/
│   ├── lora-simulator.toml       ← 主配置文件（必须）
│   ├── simulation-config.json    ← 多设备类型配置（可选）
│   ├── devices_dynamic.json      ← FUOTA 设备配置（可选）
│   └── base_devices_export.csv   ← 设备模板（可选）
└── payload_en_decoder/
    └── codec-release/
        └── vendors/
            └── milesight-iot/
                └── devices.json   ← 设备类型定义（必须）
```

### 主配置文件（lora-simulator.toml）

#### 1. 基本配置

```toml
[general]
# 日志级别：debug=5, info=4, warning=3, error=2, fatal=1, panic=0
log_level = 4

# 频率计划：EU868, CN470, AS923-1, AU915, IN865, RU864, KR920 等
channel_plan = "EU868"
```

#### 2. ChirpStack API 配置

```toml
[lora-simulator.api]
# ChirpStack Application Server 地址（不含协议头，协议由 insecure 决定）
server = "192.168.1.100"

# API 登录路径
login_url = "/api/internal/login"

# 登录用户名
username = "admin"

# 登录密码
password = "admin"

# 测试前是否清理旧数据
clean_before_test = true

# 测试后是否删除所有数据
teardown_after_test = false

# 测试功能（逗号分隔）：normal, bacnet, fuota, modbus
test_feature = "normal"

# 是否每次创建新设备
use_new_device = true

# TLS 配置
# true: 使用 HTTP（不加密）
# false: 使用 HTTPS（跳过证书验证）
insecure = false
```

#### 3. MQTT 集成配置

```toml
# Application Server MQTT 集成（用于统计上行数据）
[lora-simulator.integration.mqtt]
server = "tcp://192.168.1.100:1883"
username = "lorawan"
password = "your_password"

# Network Server MQTT 后端（用于网关通信）
[lora-simulator.gateway.backend.mqtt]
server = "tcp://192.168.1.100:1883"
username = "lorawan"
password = "your_password"
```

#### 4. 模拟器配置

```toml
[[simulator]]
# 租户 ID（需要在 ChirpStack 中创建）
tenant_id = "f6f7d81d-647f-4c7f-8409-3e5218c0c523"

# 模拟持续时间（0s 表示无限运行）
duration = "0s"

# 是否启用串行入网（批量入网，避免服务器过载）
sequence_join = true

# 串行入网间隔
sequence_join_interval = "2s"

# 每批激活的设备数量
sequence_device_number = 1

# 设备激活超时时间
activation_time = "100s"

# 设备配置
[simulator.device]
# 设备数量
count = 10

# 上行数据间隔
uplink_interval = "300s"

# FPort
f_port = 85

# 负载数据（十六进制）
payload = "010203"

# 频率 (Hz)
frequency = 868100000

# 带宽 (Hz)
bandwidth = 125000

# 扩频因子
spreading_factor = 7

# 网关配置
[simulator.gateway]
# MQTT 主题模板
event_topic_template = "gateway/{{ .GatewayID }}/rx"
command_topic_template = "gateway/{{ .GatewayID }}/tx"

# 每个设备被多少个网关接收（随机选择）
min_count = 3
max_count = 5
```

#### 5. Prometheus 监控配置

```toml
[prometheus]
# Prometheus 指标端点绑定地址
bind = "0.0.0.0:9000"
```

### 多设备类型配置（simulation-config.json）

**功能说明**：支持同时模拟多种设备类型，每种设备拥有独立的上行配置。

**配置文件路径**：`cmd/lora-simulator/config/simulation-config.json`

**配置示例**：

```json
{
    "device_types": [
        {
            "device_id": "em300_th",
            "count": 5,
            "uplink_paused": false,
            "uplink_confirm": false,
            "uplink_interval": 300000
        },
        {
            "device_id": "vs330",
            "count": 10,
            "uplink_paused": false,
            "uplink_confirm": false,
            "uplink_interval": 120000
        },
        {
            "device_id": "wt201",
            "count": 2,
            "uplink_paused": false,
            "uplink_confirm": true,
            "uplink_interval": 180000
        }
    ]
}
```

**配置字段说明**：

| 字段 | 类型 | 说明 | 示例 |
|-----|------|------|-----|
| `device_id` | 字符串 | 设备类型 ID（对应 devices.json 中的 id） | `"em300_th"` |
| `count` | 整数 | 该类型设备的数量 | `10` |
| `uplink_paused` | 布尔 | 是否暂停上行数据发送 | `false` |
| `uplink_confirm` | 布尔 | 是否使用确认上行（ConfirmedDataUp） | `false` |
| `uplink_interval` | 整数 | 上行间隔（毫秒） | `120000`（120 秒） |
| `test_data_override` | 字符串 | 自定义测试数据文件路径（可选） | `"path/to/test-data.json"` |

**注意事项**：
- 如果不使用多设备类型模式，删除或重命名此文件即可
- `device_id` 必须在 `devices.json` 中有定义
- `uplink_interval` 单位为毫秒（1000 = 1 秒）

### 设备类型定义（devices.json）

**配置文件路径**：`cmd/lora-simulator/payload_en_decoder/codec-release/vendors/milesight-iot/devices.json`

**配置示例**：

```json
{
    "version": "1.0.0",
    "devices": [
        {
            "id": "em300_th",
            "name": "EM300-TH",
            "description": "Temperature & Humidity Sensor",
            "catalog": "em300",
            "sn": "6136",
            "deveui": "24e124136",
            "device_profile": ["ClassA-OTAA"],
            "decoder_script": "",
            "encoder_script": "payload_en_decoder/codec-release/vendors/milesight-iot/em300-th/em300-th-node-encoder.js",
            "test_data": "payload_en_decoder/codec-release/vendors/milesight-iot/em300-th/em300-th-test-data.json",
            "default_fport": 85
        }
    ]
}
```

**字段说明**：
- `id`：设备类型唯一标识符（用于 simulation-config.json 引用）
- `encoder_script`：JavaScript 编码器脚本路径
- `test_data`：测试数据 JSON 文件路径
- `default_fport`：默认 FPort

- 获取可用 BACnet 对象列表
- 根据测试数据过滤对象

**查看日志**：
```bash
grep "BACnet" simulator.log
```

## 常见问题

### Q1: 设备无法入网

**症状**：设备发送 JoinRequest 但没有收到 JoinAccept。

**排查步骤**：

1. **检查 AppKey 是否正确**：

```bash
grep "AppKey" simulator.log
```

确保模拟器使用的 AppKey 与 ChirpStack 中配置的一致。

2. **检查 MQTT 连接**：

```bash
grep "MQTT" simulator.log
```

确保 MQTT Broker 连接成功。

3. **检查网络服务器日志**：

查看 ChirpStack Network Server 的日志，确认是否收到 JoinRequest。

4. **增加激活超时时间**：

```toml
activation_time = "200s"  # 增加到 200 秒
```

---

### Q2: 设备入网后无上行数据

**症状**：设备成功入网，但没有发送上行数据。

**排查步骤**：

1. **检查 uplink_paused 配置**：

```json
{
    "device_id": "em300_th",
    "uplink_paused": false  // 确保为 false
}
```

2. **检查上行间隔配置**：

```toml
uplink_interval = "300s"  # 确保不是太长
```

3. **查看设备状态**：

```bash
grep "deviceStateActivated" simulator.log
```

确保设备状态为 `deviceStateActivated`。

---

### Q3: MIC 校验失败

**症状**：日志中出现 "invalid MIC" 错误。

**原因**：
- AppKey 配置错误
- 会话密钥派生错误
- 帧计数器不同步

**解决方法**：

1. **重置设备**：

```toml
clean_before_test = true
use_new_device = true
```

2. **检查 AppKey**：

确保 CSV 文件中的 AppKey 与 ChirpStack 配置一致。

---

### Q4: 编解码器错误

**症状**：日志中出现 JavaScript 执行错误。

**排查步骤**：

1. **检查编码器脚本路径**：

```json
{
    "encoder_script": "payload_en_decoder/codec-release/vendors/milesight-iot/em300-th/em300-th-node-encoder.js"
}
```

确保文件存在。

2. **测试编码器**：

启用编解码测试模式：

```toml
[lora-simulator.test_payload_codec]
enable = true
```

3. **检查测试数据格式**：

确保 `*-test-data.json` 格式正确，匹配编码器期望的输入。

---

### Q5: 服务器过载

**症状**：大量设备同时入网导致服务器响应慢或超时。

**解决方法**：

启用串行入网：

```toml
sequence_join = true
sequence_join_interval = "2s"
sequence_device_number = 5
```

调整参数：
- 减少每批设备数量（`sequence_device_number`）
- 增加批次间隔（`sequence_join_interval`）
- 增加激活超时时间（`activation_time`）

---

### Q6: Prometheus 指标无数据

**症状**：访问 `http://localhost:9000/metrics` 无响应。

**排查步骤**：

1. **检查 Prometheus 绑定地址**：

```toml
[prometheus]
bind = "0.0.0.0:9000"
```

2. **检查端口占用**：

```bash
lsof -i :9000
netstat -an | grep 9000
```

3. **检查防火墙**：

```bash
sudo ufw allow 9000/tcp
```

## 最佳实践

### 1. 生产环境配置建议

```toml
[general]
log_level = 4  # Info 级别，避免日志过多

[lora-simulator.api]
clean_before_test = false
teardown_after_test = false
insecure = false  # 使用 HTTPS

[[simulator]]
sequence_join = true
sequence_join_interval = "3s"
sequence_device_number = 10
activation_time = "300s"

[simulator.device]
uplink_interval = "600s"  # 减少服务器负载
```

### 2. 测试环境配置建议

```toml
[general]
log_level = 5  # Debug 级别，详细日志

[lora-simulator.api]
clean_before_test = true
teardown_after_test = true
insecure = true  # 使用 HTTP（快速测试）

[[simulator]]
sequence_join = false  # 并行入网（压力测试）
activation_time = "60s"

[simulator.device]
uplink_interval = "30s"  # 快速验证
```

### 3. 性能优化建议

**大规模设备模拟（500+ 设备）**：

1. **增加系统资源**：
   - 内存：4 GB+
   - CPU：4 核+

2. **优化配置**：
   ```toml
   sequence_join = true
   sequence_join_interval = "2s"
   sequence_device_number = 10
   uplink_interval = "600s"
   ```

3. **监控资源使用**：
   ```bash
   # 监控内存
   watch -n 1 free -h

   # 监控 CPU
   top
   ```

### 4. 安全最佳实践

1. **不要在配置文件中硬编码密码**：

使用环境变量：
```bash
export CHIRPSTACK_PASSWORD="your_password"
export MQTT_PASSWORD="your_mqtt_password"
```

2. **使用 HTTPS**：
```toml
insecure = false
```

3. **限制 Prometheus 访问**：
```toml
bind = "127.0.0.1:9000"  # 只允许本地访问
```

### 5. 日志管理

**日志轮转**（使用 logrotate）：

```bash
# 创建配置文件
sudo vi /etc/logrotate.d/lora-simulator
```

```
/path/to/lora-simulator/cmd/lora-simulator/simulator.log {
    daily
    rotate 7
    compress
    delaycompress
    notifempty
    create 0644 root root
}
```
